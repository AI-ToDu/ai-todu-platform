# AI-ToDu · Product landing

Responsive academic product landing · English by default / Latin American Spanish.

Plain HTML, CSS and JavaScript. No runtime packages, analytics, fabricated testimonials, subscription checkout or claimed production fiscal/payment integrations.

```sh
npm run check
python -m http.server 8851 --bind 127.0.0.1
```

Open `http://127.0.0.1:8851`. Start `npm run demo` in the frontend repository for the local CTA target at port 8850. On public hosting the CTA links to the actual workspace Pages URL and forwards locale/demo profile. Existing authenticated sessions remain governed by the workspace; profile hints do not change an authenticated user's role.

Sections cover purpose, capabilities, workflow, user segments, team, demo CTA, project contact and academic terms/privacy. The hero preview is labelled illustrative. Menu, language and native dialog support keyboard interaction; mobile uses stacked sections and a collapsible nav. Translation/anchor/asset checks run in GitHub Actions for fix branches and PR.
